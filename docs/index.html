まずは全体像

予測を作り、間違いから調整する

ニューラルネットワークは、数字を受け取り、計算を重ねて結果を出す仕組みです。画像も文章も、コンピューターに渡すときは数字として表します。

  1. 入力：たとえば「勉強時間」
  2. 予測：入力から「点数」を計算
  3. 誤差：予測と実際の点数の差
  4. 学習：差が小さくなるよう、計算に使う値を変える

この例では入力が1個ですが、画像なら大量の画素値、文章なら単語を表す数値列などが入力になります。

考えてみよう

「練習問題だけ満点、初めての問題は苦手」なAIには、どんな問題が起きているでしょう？

考えるヒント

練習問題を覚えたことと、初めての問題にも使える規則を学んだことは違います。第5章で確かめます。

02

手を動かす実験 1

1個のニューロンを操作する

入力 x に重み w を掛け、バイアス b を足すと、z = x × w + b です。重みは入力の影響の大きさ、バイアスは結果をずらす値です。下の値を動かしてください。

計算結果2.0 × 0.7 + 0.1 = 1.5

ReLU を通した出力：1.5

ReLU（レル） は、0より小さい値を0にし、0以上ならそのまま通す活性化関数です。式は max(0, z)。複雑な関係を表す助けになります。

やってみよう

出力を0にする設定を2通り探しましょう。入力・重み・バイアスをどう変えましたか？

手を動かす実験 2

「学習」で何が変わる？

目標を y = 2x + 1 とします。モデルは最初、違う重みとバイアスを持っています。学習では「予測と正解の差」を表す損失を小さくするよう値を更新します。

重み w = 0.00 / バイアス b = 0.00

平均二乗誤差（MSE） = 0.000

点は x = −2, −1, 0, 1, 2 の5件。1回ごとに5件すべてを使います。

● 正解━ 予測

MSE は各予測の「差の2乗」の平均です。学習率は1回で値をどれくらい動かすかを決めます。この実験では学習率0.05の勾配降下法を使います。

考えてみよう

10回進めたとき、重み・バイアス・MSEはどう変化しましたか？「学習は答えを保存すること」という説明は正確でしょうか？

層を重ねる理由を、XORで知る

1個のニューロンは、入力を1本の直線で分けるような判定が得意です。しかし、次の XOR（どちらか一方だけ1なら1）は、1本の直線では分けられません。

入力と出力の間に隠れ層を置くと、途中で複数の特徴を作れます。たとえば「AかBの少なくとも一方が1」と「AとBが両方1」を組み合わせれば XOR を表せます。実際に学習させるコードは Python演習 03 にあります。

考えてみよう

入力が (1, 1) のとき、なぜ出力は0でしょう？ 2つの途中の特徴を使って説明してみましょう。

05

作ったあとが大切

本当に使えるかを確かめる

学習に使ったデータだけで成績を出すと、実力を見誤ることがあります。訓練用データで値を調整し、テスト用データで初めての入力に通用するか確かめます。

誤答を1件ずつ見て、入力の偏り、正解ラベルの誤り、現実と違う条件がないか調べます。データが偏れば、モデルの判断も偏り得ます。

例：明るい場所の写真だけで学習した姿勢推定モデルは、暗い場所でうまく動かないかもしれません。「正解率90%」だけでなく、どんなデータで測った90%かを残しましょう。
